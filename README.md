# BOOK-VAULT-
ONLINE AUDIO AND VIDEO BOOK PLATFORM 
What is Book Vault? A personal audio/video library that runs as an app on your phone or computer. Add audio books, audio scripts (text read aloud), and video scripts; open copied links (YouTube, Vimeo, xvideos, xnxx, xhamster, direct files); import from Drive/Dropbox/OneDrive links; track progress, streaks and goals; use bookmarks, sleep timer, covers, PDFs, notes, tags. Works offline. Everything is stored on your device, per account.

2. Install (one time). Unzip → drag the folder onto Netlify Drop / Vercel / GitHub Pages (all free, all HTTPS) → open the link in Chrome/Edge/Safari → tap ⬇ Install app in the top bar (iOS Safari: Share → Add to Home Screen). The icon lands on your home screen and works offline after the first visit.

3. Create your account (one time). Open the app → Register tab → display name, username, password (4+ chars, stored SHA-256-hashed) → optionally tick the 18+ box → Create account. You're logged in automatically from then on. Switch accounts via 📊 → Log out. Honest note: accounts live on this device only — a privacy screen, not real security; there's no password reset.

4. Add your first book. Tap ＋ Add book, choose a format at the top: 🎧 Audio book (attach an MP3/M4A/WAV), 🗣 Audio script (paste text — the 🗣 player button reads it aloud), 🎬 Video script (attach a video + screenplay). Add title, author, category, tags, notes, cover image, even a PDF/TXT material file. The 🔎 Quick-search Google button inside the dialog opens google.com/search in a new tab to find scripts and content. The ☁️ Import button in the header takes a Drive/Dropbox/OneDrive share link, converts it to a direct download, and fetches it into your vault as the right type automatically.

5. Use the player. ⏮/⏭ move through your queue (auto-advances; double-tap ⏭ to toggle), ⏪⏩ skip 15/30 s, seek saves your spot, 1× changes speed, 🔊 volume, 🔖 bookmarks + 📋 list, ⏱ sleep timer (5–60 min), 🗣 read-aloud, ↗ share. 🔗 Open Link (or press L): paste any copied link → ▶ Open. YouTube/Vimeo/Dailymotion/xvideos/xnxx/xhamster and direct .mp4/.mp3/.m3u8 links play inside the app; unknown sites fall back to a new tab. Keyboard: Space, ←/→, /, L, ?, Esc.

6. Organize. Search box; All/In-progress/Finished chips; 5 sort modes; category bar with counts; 🎲 shuffle; "▶ Continue listening" rail; per-card Play/Edit/Export-audio/Open-material/Hide/Delete.

7. The 18+ gate. Erotic (18+) content is invisible unless the account confirmed 18+ and the opt-in in 📊 Stats is on; cards carry a red 18+ badge and a 🙈 hide button. The app ships no adult content — this only manages material you add.

8. Stats & backup. 📊 shows books/finished/in-progress/hours listened, 🔥 day streak, today-vs-goal minutes. ⬇ Export backup packs everything — including audio and video — into one JSON file; ⬆ Import backup rebuilds it on any device.

9. Troubleshooting (short version). No install button → must be HTTPS + Chrome/Edge/Safari. "Audio missing" → re-attach via ✎ or import backup. Link import fails → host blocks CORS; use ↗ Open link then attach locally. Embed blank → that site blocks embedding; use ↗ New tab. Forgot password → no reset (no server); new account + backup import.
